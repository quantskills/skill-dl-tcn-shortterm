# 数据与因果契约

## 必需输入证据

运行真实数据研究前，至少确认：

- 数据 manifest、schema version、数据指纹和来源说明；
- 明确的信号日期、证券、分钟时间戳和交易日历；
- 每日 point-in-time 标的池及其可用时间；
- 原始标签值、标签结束时间 `label_end_at` 和四期限有效掩码；
- 已冻结的 train/validation/test 用途与 purge/embargo 边界；
- 输出根目录为空且位于未跟踪运行目录。

缺少任一关键项时停止，不要推测字段、用当前成分股回填历史或把未知时间当作当时可见。

## 分钟线处理

1. 原始 1 分钟行情按交易时段因果聚合为 5 分钟 OHLCV。
2. 不跨午休、隔夜或停牌空档伪造连续 bar。
3. 输入截至信号日收盘；预测在收盘后可用，经济评估最早从下一交易日开盘执行。
4. 真实行情、派生特征、窗口索引、memmap 和训练产物留在仓库外或被 Git 忽略的位置。
5. 大样本优先使用 Parquet/Arrow 扫描与 memmap 窗口，不把完整五年分钟数据复制进进程或仓库。

## PIT 与切分

- 标的池、上市/停牌状态、复权事件、ADV20、市值和行业信息都必须以信号时点可见版本为准。
- walk-forward 以 `signal_date` 顺序扩展训练历史，禁止随机拆分证券或样本行。
- 每个边界根据实际 `label_end_at` 动态 purge；标签越过下一阶段起点的训练样本必须移除。
- embargo 与 pre-test gap 分开记录；最终 test/sealed 数据永不回流训练。
- 缺失值处理、裁剪、标准化、特征选择和其他可学习变换每折只在训练段拟合。

## 安全边界

Skill 不负责登录 PandaData 或其他数据源，不读取 `.env`、token、SDK 用户文件或浏览器会话。需要供应商接入时，只接受调用方已经准备好的本地规范数据集和非秘密 manifest；外部数据源保持只读且必须有界导出。
