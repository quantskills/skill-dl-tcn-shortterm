# PandaData 五年 PIT 分钟数据试验落地提示词 v1

你是 `skill-dl-tcn-shortterm` 的数据工程与量化研究执行者。请在不泄露凭据、不修改外部 DuckDB、不连接券商、不触碰封存测试集的前提下，为 TCN 短线横截面研究建立一个可恢复、可审计的 PandaData 真实数据试验，并用真实数据执行工程验证。

## 已确认事实

- 研究区间固定为最近五个已完整结束的自然年：`2021-01-01` 至 `2025-12-31`。
- 供应商 SDK 为 `panda_data==0.0.12`；认证、数据请求必须在同一进程完成。
- 系统代理会干扰 PandaData；只在下载进程内移除 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`，不得永久修改系统代理。
- SDK 默认会持久化加密凭据；必须在认证前禁用其持久化钩子，且运行前后确认项目根目录不存在 `user.json`。
- `get_index_weights(index_symbol="000300.SH", ...)` 实测按交易日返回沪深300成分和权重；年度查询会触发套餐结果集上限 `600003`，必须按自然月请求。
- `get_stock_min(..., frequency="1m")` 实测单股完整交易日返回 240 行，字段包括 `symbol/date/datetime/OHLCV/amount`，但时间顺序为倒序。
- 规范输入使用 `Asia/Shanghai`、分钟结束时间、`000001.XSHE` / `600000.XSHG` 标识，并按证券和时间升序排列。

## 固定试验口径

- PIT 候选池：每个交易日当日沪深300成分。
- 有界横截面：每个交易日按当日公开权重降序选前 100 只；同权重按股票代码稳定排序。
- 原始频率：1 分钟。不得把供应商 5 分钟线伪装为原始 1 分钟线。
- 请求分片：按自然月、每批最多 25 个股票代码；每个自然月请求该月每日前100成分的并集，落盘前再按 `trade_date × symbol` 的当日 PIT 成员关系过滤。
- 原始层：分片 Parquet，仅包含规范 `raw_1m` 字段和质量标记。
- 研究层：从原始层因果聚合为 5 分钟条；未知连续竞价缺口不得插值。
- 质量门禁：完整股票交易日必须有 240 个 1 分钟结束条和 48 个完整 5 分钟条；每日至少 80 只完整证券才可进入连续训练覆盖区间。
- 训练覆盖：10 个交易日回看，最长 5 个交易日标签；任何不合格日期切断连续窗口。

## 实现要求

1. 先通过公共接口测试锁定四个缝：供应商分钟帧规范化、每日 PIT top-N 选择、月度请求计划、可恢复分片清单。
2. 外部 SDK 通过协议注入；单元测试不得联网，不得模拟内部实现。
3. CLI 只从 `PANDADATA_USERNAME`、`PANDADATA_PASSWORD` 环境变量读取秘密，不接受命令行密码参数，不输出 token、账号或密码。
4. 每个分片先写临时文件，再原子改名；已完成且哈希匹配的分片可跳过，冲突文件必须 fail closed。
5. 按月请求并保存权重、PIT 标的池、分片索引、哈希、SDK版本、查询参数、行数、日期范围、证券数和质量统计；最终 manifest 不含秘密。
6. 真实数据与运行产物只写入 `.gitignore` 已覆盖的 `artifacts/`，源代码、测试、非秘密配置和文档才可进入 Git。
7. 下载过程中遇到限流、网关瞬时错误或超时，采用有界指数退避；认证失败、权限不足、结果集超限和模式漂移立即终止并给出明确阻断原因。
8. 全量下载前先执行一个月的验收切片；通过后再按 2021→2025 顺序恢复式执行。
9. 数据完成后运行覆盖审计，再用覆盖完整的日期范围执行真实 TCN 工程测试；不要把一次训练结果描述为 Alpha、生产就绪或收益承诺。
