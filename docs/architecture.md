# Architecture

本项目采用离线、供应商无关的研究流水线。下述组件均已实现；真实行情、真实硬件性能和封存 Alpha 评估仍需由研究所有者显式执行。

## Component boundaries

1. **Provider adapter**：把外部供应商或本地原始文件转换为规范字段，不被模型代码直接依赖。
2. **Canonical store**：保存分区 Parquet/Arrow 数据、清单、模式版本和数据指纹；真实数据不进入仓库。
3. **Sample builder**：按 PIT 标的池、信号时点、回看窗口和标签时序构建样本，并生成可重建的窗口索引或 memmap 缓存。
4. **Model runner**：通过统一模型协议训练 Bai TCN、TCN-lite、ModernTCN 及传统基准。
5. **Evaluator**：使用同一时间切分、样本集合和成本假设计算统计指标、吞吐指标与离线组合结果。

这些边界只通过版本化数据契约传递信息，模型不得读取供应商 API、未来标的状态或回测产生的字段。

## Multi-horizon model contract

- 标准神经网络输入形状为 `[batch, feature, time]`，基准时间长度约为 480。
- Bai TCN 主干共享因果时序表征，并通过四个独立回归头输出 `[batch, 4]`，列顺序固定为 `[1d, 2d, 3d, 5d]`。
- 四个标签已经分别映射到 `[-1, 1]`，首版对有效标签使用等权 Smooth L1 损失；缺失标签必须通过显式掩码排除，不能填成零。
- 单期限独立模型仅作为负迁移消融，不是默认训练路径。
- TCN-lite 与 ModernTCN 必须实现相同输入、输出、掩码和预测期限契约，避免因任务定义不同产生虚假的模型优势。
- TCN-lite默认保持逐元素block dropout以兼容既有模型；实验配置可显式选择沿时间共享掩码的channel dropout、仅作用于最后时刻表示的head dropout，以及非零权重衰减。所有变体都必须记录dropout位置/类型与优化器，且不得改变因果卷积或感受野口径。

## Bai TCN baseline

- 基准输入长度为约 480 个 5 分钟时间步。
- 主干使用 7 个残差块；每块包含两层 `Conv1d`，卷积核为 3，对应扩张率依次为 `1, 2, 4, 8, 16, 32, 64`。
- 对每层卷积显式执行 `(kernel_size - 1) × dilation` 的纯左侧填充，卷积本身不做对称 padding；任何输出都不得依赖右侧或未来时间步。
- Bai 双卷积残差块的感受野按 `R = 1 + 2 × (kernel_size - 1) × Σ(dilation)` 计算，因此默认配置的感受野是 509，能够覆盖 480 步基准窗口。
- 默认隐藏通道宽度为 64，使用 WeightNorm、ReLU 和 Dropout 0.1；当输入与输出通道不一致时使用 `1×1` 投影形成残差路径。
- 四个期限头读取主干最后一个有效时间步的表征。通道宽度和 Dropout 是可配置超参数，但任何试验都必须记录实际感受野并拒绝感受野小于输入窗口的配置。
- 首版禁用 BatchNorm，避免批次组成和时间分布变化影响时序统计。

## Comparison policy

Ridge、LightGBM、LSTM、GRU、TCN-lite、Bai TCN 与 ModernTCN 的比较必须固定数据版本、walk-forward 切分、特征可用性、标签版本和评估集合。速度声明必须同时报告硬件、批大小、混合精度、样本吞吐量、达到最佳验证指标的时间和峰值内存。

CPU 性能比较还必须固定并记录 PyTorch intra-op threads，且在线程作用域退出后恢复调用进程原值。吞吐至少拆分为模型前后向步、训练数据管线和包含逐轮验证的完整周期；模型选择指标统一按 `signal_date × horizon` 计算横截面 Spearman RankIC。扁平化全部日期或期限得到的相关系数不能再标记为 RankIC。

用于稳定性诊断的派生 folds 只能从既有 ordinary `train + validation` 行生成；任何原始 `test`、`sealed_holdout` 或 `sealed=true` 行必须排除。派生 expanding/sliding 清单继续按实际 `label_end_at` 动态 purge，并保存源哈希与不可变指纹。

## Walk-forward validation

- 所有切分都以 `signal_date` 为单位，使用训练历史锚定、持续扩展的 walk-forward；禁止按证券或样本行随机拆分。
- 训练、验证和测试区间长度由数据覆盖范围决定并通过版本化配置记录，不在缺少真实数据时虚构固定年份。
- 每个边界根据样本的实际 `label_end_at` 自动 purge；只要训练样本的任一有效期限标签越过下一阶段起点，该样本就不得留在训练段。
- 验证或测试区间结束后设置 5 个交易日 embargo；隔离期结束前，相邻日期不得进入后续折的训练集。最终封存测试段永不回流训练。
- 缺失值统计、裁剪阈值、标准化参数、特征选择和任何可学习预处理都必须在每折训练段单独拟合，再只读地应用到验证与测试段。
- 模型选择和早停只读取验证指标；最终测试段仅在配置、权重和决策阈值冻结后评估一次。
- 每折必须保存数据指纹、日期边界、被 purge/embargo 的样本数、预处理状态指纹和随机种子，保证结果可复查。

## Economic evaluation

- 1、2、3、5 日预测分别形成独立组合，禁止把不同期限的分数或持仓混成一个未定义策略。
- 每个组合在信号后的下一交易日开盘尝试等权买入当期分数前 10% 的股票。
- 对 `h > 1`，每日新信号形成一个独立持仓批次，各有效批次按 `1/h` 分配该期限组合的资本并持有到计划退出时点，从而避免把 `h` 日预测错误地按日全部换仓。
- 主报告使用可实现多头组合；前后 10% 多空组合只报告为排序诊断，并明确标注不可直接执行。
- 所有经济结果必须同时报告毛收益、净收益、换手率、最大回撤、成本敏感性、无法成交比例以及行业和规模暴露。
- 计划买入时若股票停牌、封在涨停或因其他执行约束无法成交，对应资金保持为现金；不得在后续日期使用回看价格补单。
- 计划卖出时若停牌、封在跌停或无法成交，持仓及其风险敞口延续到首次可成交的开盘，并使用实际延迟退出时间计算收益。
- 每笔成交额最多为执行日前 20 个交易日平均成交额的 5%；只允许使用当时已知的成交额历史，超过部分视为未成交。
- 成本配置必须带生效日期，分别表达买卖双边佣金、卖出侧税费和双边滑点；除基准配置外，强制报告单边 5、10、20 bps 滑点压力测试。
- 沪深 A 股 T+1、停复牌和价格限制必须由版本化交易日历及交易状态字段驱动，不能由模型输出绕过。

## Implementation status

数据聚合、PIT 标的池、窗口/标签、walk-forward、流式缓存、统计与神经基准、Bai TCN、TCN-lite、可执行回测、性能测量、证据包和 Promotion 状态机已经通过合成测试。ModernTCN 是 validation-only 后续实验。尚未产生真实市场 Alpha、真实硬件速度或一次性封存评估收据。
